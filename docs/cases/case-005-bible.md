# Case bible — Case 005: The Wrong Date (DRAFT for review)

Status: **proposal**. CLAUDE.md gives the title only. It inherits the open
question from Case 004 (approved scope guard): *when* was the File 0091
photograph taken? Everything below is **[Proposed]** unless marked
**[Canon]** or **[Rule]**. Nothing is built until approved.

## Scope guard

**[Rule]** Case 005 may establish that the photograph's date is **wrong** and
that the records **contradict each other**. It must not explain *how*: no
time travel, no forgery motive, no person behind it. Cases 006–007 own the
larger reveals. The player should finish with a sharper, more unsettling
question, not an answer.

## Premise

Following Case 004, the archive asks a narrow technical question: can the
date on File 0091 be relied on? Specialist records arrive: a camera manual, a
manufacturer's catalogue, a paper data sheet, a companies-register extract,
and an Estates photograph of the reading room taken at installation in 1998.

- **Assignment:** "Determine whether the date on File 0091 can be relied on.
  Record only what the evidence supports."

## Evidence

| # | Item | Type | What it shows |
|---|---|---|---|
| 1 | File 0091 photograph (copy) | Photo (existing artwork) | New region **terminal casing**: a maker's badge reads *HALDEN 486*. A small badge is added to the artwork. |
| 2 | Camera manual extract | Document | Date-back model: *"The date is set by hand on the back of the camera and may be set to any date from 1980 to 2019."* |
| 3 | Halden product catalogue, 1996 | Document | *"Halden 486 terminal, beige case. Introduced March 1996."* |
| 4 | Installation photograph, 1998 | Photo (new artwork) | Estates photograph: the same desk, terminal, lamp and window, labelled *"Reading room, position 7, installed 2 Feb 1998"*. No date imprint. |
| 5 | Photographic paper data sheet | Document | Backprint code on the File 0091 print = stock made 1980–82, shelf life two years. |
| 6 | Companies register extract | Document | Kessler Photo, 3 Market Street: incorporated 1971, **dissolved 1989**. |
| 7 | Asset register (copy) | Document | NA-07 installed 1998 (as before). |

**Discovery (new mechanic proposed): photo comparison.** The player opens
File 0091 beside the 1998 installation photograph, with the views synced.
Matching a region in both, the terminal badge, records a discovery that files
**Item 4a: Estates comparison note**: *"Same desk, same terminal, same
position. Lamp and papers differ."* Required.

## Supported conclusion

1. The date imprint does not establish when the photograph was taken: it is
   set by hand.
2. The scene shown cannot date from before 1996. The terminal was introduced
   that year, and NA-07 was installed in 1998.
3. The print carries the stamp of a lab dissolved in 1989, on paper made in
   1980–82.
4. When and how the print was made cannot be established from the records.

**[Rule]** Never accept:
- "taken in 1981"
- "taken in 1998 and the date set wrongly on purpose" (a motive)
- "a forgery"
- "Kessler printed it after 1989"
- any explanation of the contradiction

## Findings (all existing question types)

1. *Does the date imprint establish when the photograph was taken?*
   Supported: **No. It is set by hand.** Cite the camera manual.
2. *What is the earliest the scene could date from?* Supported: **1996.**
   Cite the catalogue and the comparison note.
3. **Select all that apply:** *Which records date the print rather than the
   scene?* Supported: paper data sheet, companies register (and the lab
   stamp). Not the catalogue, installation photo, or asset register.
4. **Ordering:** *Put these dates in order:* paper made (1980–82); imprint
   date (14 Oct 1981); Kessler dissolved (1989); terminal introduced (1996);
   NA-07 installed (1998). Players see the print's evidence ends before the
   scene's evidence begins.

## Board relationships the records support

- Camera manual **contradicts** File 0091 photograph (the imprint is not evidence of the date)
- Catalogue **contradicts** File 0091 photograph (no Halden 486 in 1981)
- Installation photo **same subject** File 0091 photograph (same position)
- Comparison note **derived from** installation photo
- Paper data sheet **corroborates** companies register (both place the print's making before 1990)
- Asset register **corroborates** installation photo (installed 1998)

## Thread to the long mystery

- The installation photograph is labelled **position 7**. It's quiet
  confirmation that "NA-07" is a place as well as a machine.
- **End beat — choose one:**
  - **A:** the asset register's "Installed: 1998" gains a handwritten note in
    the same hand as the ledger: *"See 0091."*
  - **B:** the print's chain of custody gains an entry **above** the
    player's: *"14 Oct 1981 · Night archivist (Workstation NA-07) · Unfiled
    tray · Placed."* It reads as the player having filed it in 1981.
    Stronger, and it sets up Case 006 ("Someone Is Watching").
