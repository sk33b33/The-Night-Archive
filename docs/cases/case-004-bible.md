# Case bible — Case 004: File 0091 (DRAFT for review)

Status: **proposal**. CLAUDE.md gives the title and the Case 001 end anomaly
(**[Canon]**: File 0091 holds a photograph of the player's workstation dated
14 October 1981; the asset register says the workstation was installed in
1998; unexplained). Everything else is **[Proposed]**. Nothing is built until
approved.

## Scope guard

Case 005 is *The Wrong Date*. **[Rule]** Case 004 must not settle *when* the
photograph was taken or *how* a 1998 workstation appears in it. Case 004 is
about **provenance**: how File 0091 entered the archive, and what the
records can and cannot say about it.

## Premise

The archive formally assigns File 0091 for review. Its "Unfiled" card
becomes **Case 004** once Case 003 is closed. The photograph and asset
register from Case 001's anomaly become case evidence, with new records
beside them.

- **Assignment:** "File 0091 has no intake record. Establish how it entered
  the archive. Record only what the evidence supports."

## Evidence

| # | Item | Type | What it shows |
|---|---|---|---|
| 1 | File 0091 photograph | Photo (existing artwork) | As in Case 001. Adds a fourth region, **papers on the desk**. |
| 2 | The print itself | Object | The reverse: lab stamp *"Kessler Photo, Bellwether"* with no order number. Paper backprint code for 1980–82 stock. Chain of custody: *"Found in the Unfiled tray, reading room. Recorded by the night archivist (Workstation NA-07)."* That is **the player**. No earlier entries. |
| 3 | Intake ledger, October 1981 | Document | Entries 0089 (12 Oct), 0090 (13 Oct), **0091 — line ruled through, no date**, 0092 (15 Oct). The number was taken and then voided. |
| 4 | Kessler Photo order book | Document | 15 Oct 1981: *one film, one print*, account **"Records facility, night"**. Collected 16 Oct, signature illegible. No order number is carried onto prints. |
| 5 | Building history | Document | The reading room was created in the 1997–98 refit. In 1981 the space was *"Storage B — sealed"*. |
| 6 | Asset register | Document (existing) | Workstation NA-07, installed 1998. Previous asset at this position: none recorded. |

**Discovery:** examining the **papers on the desk** region files **Item 1a:
Enlargement of desk papers**. The top sheet is an intake-ledger page with the
number **0091** written and not yet ruled through. This is required for the
findings, because it is what connects the ledger to the photograph.

## Supported conclusion

1. File 0091 did not enter the archive through intake. The number was
   reserved in 1981 and voided, and nothing was filed under it then.
2. The photograph shows the number 0091 being written on an intake page
   (the enlargement).
3. A single print was ordered on the facility's night account in October
   1981. Whether the print in File 0091 is that print **cannot be
   established** (no order number on the print).
4. Who placed File 0091 in the archive cannot be established.

**[Rule]** Never accept:
- "the photo was taken in 1981" or "the photo was taken after 1998" (Case 005's question)
- "the night archivist filed it", whether the player or anyone named
- "M. collected the print"
- any explanation of the workstation contradiction

## Findings (new question type proposed)

1. *Did File 0091 come through intake?* Supported: **No. The number was
   reserved and voided.** Cite the ledger.
2. *What is written on the papers in the photograph?* Supported: **The
   number 0091 on an intake page.** Cite the enlargement.
3. *Is the print in File 0091 the one from the Kessler order?* Supported:
   **Cannot be established.** Cite the print and the order book.
4. **New type: select all that apply.** *Which records place the
   photograph's subject or print in 1981?* Supported set: the date imprint
   (photo), the paper stock (print), the order book. *Not* the asset register
   or building history, which point the other way. This teaches the player
   to separate records that agree from records that conflict, without
   resolving the date.

## Board relationships the records support

- Ledger **same subject** enlargement (the number 0091)
- Enlargement **derived from** photograph
- Print **corroborates** order book (same lab)
- Building history **contradicts** photograph (no reading room in 1981)
- Asset register **contradicts** photograph (NA-07 installed 1998)
- Building history **corroborates** asset register (1997–98 refit, 1998 install)

## Thread to the long mystery

- The order book account "Records facility, **night**" quietly echoes Case
  003's sixth call ("Records facility, night entrance"). It is not linked in
  any record.
- The print's chain of custody begins with **the player**. That is a fact,
  not an accusation, and findings never accept that the player filed it.

## End beat — choose one

- **A (proposed):** after Case 004 closes, the intake ledger's struck line
  for 0091 gains a date in the same hand: *"14 Oct"*. Unexplained, and it
  hands straight on to *The Wrong Date*.
- **B:** the print's chain of custody gains an entry *before* the player's:
  *"Placed in Unfiled tray — [blank]"*, dated the player's current shift.
