# The Night Archive — Claude Code starter kit

## Install on Android
1. Create your GitHub repository.
2. Download and extract this ZIP.
3. Upload **everything inside** to the repository root. Preserve the `.claude` directory and its subfolders.
4. Open the repo in Claude Code and start a session.
5. Send the first-session prompt at the bottom of this file.

If the GitHub mobile upload flow hides dot-folders, ensure `.claude/` is included. You can create files through GitHub's web editor if necessary.

## Included
- `CLAUDE.md`: master brief and working agreement.
- `.claude/agents/`: seven specialist agents.
- `.claude/skills/`: seven reusable skill playbooks.
- `docs/`: game design, Case 001 canon, architecture, roadmap, and acceptance criteria.

## First-session prompt
Read `CLAUDE.md` and all relevant files under `docs/` and `.claude/`. Inspect the repository and report what is present. Then implement **Phase 1 only** from `docs/ROADMAP.md`: establish the app foundation, responsive visual system, screen/navigation shell, and main menu. Do not build Case 001 yet. Do not leave inert controls. Run available checks and summarize changed files, commands run, and blockers.
