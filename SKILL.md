# Ui Ux Skill

- Prioritize mobile layout and legibility.
- Charcoal/midnight-blue surfaces, restrained teal/amber accents.
- Use spacing and hierarchy before decoration.
- Avoid excessive glow, clutter, tiny metadata, needless motion.
- Define default, focus, active, disabled, loading, and error states.
- Respect contrast and reduced motion.
- Never hide critical actions behind hover.
